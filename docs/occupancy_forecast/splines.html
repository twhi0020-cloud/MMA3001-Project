occupancy_forecast.splines

Smooth time-of-day profiles of headcount, built with the splines taught in the unit.

The seasonal-average baseline (see occupancy_forecast.models.SeasonalAverage) is a step function: every 15-minute slot has its own mean. Here the same slot means are turned into a smooth curve of headcount against time of day, one curve per room and day type. Five constructions from the unit's spline notes are compared:

  • linear - straight lines between slot means (still continuous, but slope jumps);
  • cubic - piecewise cubics with continuous slope and curvature (not-a-knot ends);
  • pchip - shape-preserving cubic Hermite: no new peaks or dips between slot means;
  • akima - smooth cubic from local slopes;
  • smoothing - a smoothing spline that does not pass through the noisy slot means; the smoothing strength is chosen by generalised cross-validation (GCV).

Interpolating splines pass through every slot mean, so they reproduce its noise; the smoothing spline trades closeness for smoothness. A headcount cannot be negative, so predictions are clipped at zero; how often a curve would have gone negative on its own is reported by SplineProfile.diagnostics() (the shape-preservation point from the notes).

Midnight and extrapolation. Time of day is circular, so the 24 h profile is repeated one day on each side before fitting. The curve is then smooth through midnight and every query lies inside the data range. Evaluation uses extrapolate=False, so a query outside the range would return NaN (and raise here) instead of a silent extrapolated value.

Hybrid forecast. A profile alone ignores what is happening now, and the earlier results show recent history matters most. SplineAnomalyForecaster therefore predicts profile(t+h) + phi * (current - profile(t)): the expected level at the target time plus a fraction phi (fitted by least squares on training data) of today's deviation from normal.

 48def _fractional_hours(ts: pd.Series) -> np.ndarray:
 49    return ((ts.dt.hour * 60 + ts.dt.minute + ts.dt.second / 60.0) / 60.0).to_numpy(dtype=float)

 52def _day_key(ts: pd.Series, grouping: str) -> np.ndarray:
 53    dow = ts.dt.dayofweek.to_numpy()
 54    return dow if grouping == "dow" else (dow >= 5).astype(int)

 57def _build_interpolant(method: str, x: np.ndarray, y: np.ndarray, w: np.ndarray):
 58    if method == "linear":
 59        return make_interp_spline(x, y, k=1)
 60    if method == "cubic":
 61        return CubicSpline(x, y, bc_type="not-a-knot")
 62    if method == "pchip":
 63        return PchipInterpolator(x, y)
 64    if method == "akima":
 65        return Akima1DInterpolator(x, y)
 66    return make_smoothing_spline(x, y, w=w, lam=None)  # lam=None -> GCV

 69def _fit_curve(method: str, slot_hours: np.ndarray, means: np.ndarray, counts: np.ndarray, pad_knots: int | None = None):
 70    """Fit one periodic profile.
 71
 72    The 24 h data is wrapped around midnight by repeating its last ``pad_knots`` points before
 73    the start (shifted by -24 h) and its first ``pad_knots`` points after the end (+24 h).
 74    ``pad_knots=None`` repeats the whole day on each side. Fitting cost grows with the number
 75    of knots, so a short wrap is cheaper; it only needs to reach beyond midnight so that every
 76    query lies inside the fitted range.
 77    """
 78    n = len(slot_hours)
 79    k = n if pad_knots is None else max(1, min(n, pad_knots))
 80    x = np.concatenate([slot_hours[n - k:] - 24.0, slot_hours, slot_hours[:k] + 24.0])
 81    y = np.concatenate([means[n - k:], means, means[:k]])
 82    w = np.concatenate([counts[n - k:], counts, counts[:k]]).astype(float)
 83    return _build_interpolant(method, x, y, w)

 86class SplineProfile:
 87    """Smooth mean headcount as a function of time of day, per room and day type.
 88
 89    Args:
 90        method: One of ``SPLINE_METHODS``.
 91        slot_minutes: Width of the time-of-day slots whose means the spline is fitted to
 92            (positive divisor of 1440).
 93        day_grouping: ``"dow"`` (a profile per day of week) or ``"weekday_weekend"``
 94            (two profiles per room, with more data per slot).
 95        min_knots: Minimum number of populated slots needed to fit a curve for a group
 96            (at least 5). Smaller groups fall back to the room-level profile.
 97        pad_hours: How much of the day is repeated either side of midnight before fitting
 98            (greater than 0 and at most 24). 24 repeats the whole day; a shorter wrap makes
 99            fitting cheaper (cost grows with the number of knots) and, for a smooth profile,
100            changes the curve very little away from midnight.
101
102    Raises:
103        ValueError: If an argument is invalid.
104    """
105
106    def __init__(self, method: str = "smoothing", slot_minutes: int = 15,
107                 day_grouping: str = "dow", min_knots: int = 8, pad_hours: float = 24.0):
108        if method not in SPLINE_METHODS:
109            raise ValueError(f"method must be one of {SPLINE_METHODS}, got {method!r}")
110        if isinstance(slot_minutes, bool) or not isinstance(slot_minutes, int) \
111                or slot_minutes <= 0 or 1440 % slot_minutes:
112            raise ValueError(f"slot_minutes must be a positive divisor of 1440, got {slot_minutes!r}")
113        if day_grouping not in DAY_GROUPINGS:
114            raise ValueError(f"day_grouping must be one of {DAY_GROUPINGS}, got {day_grouping!r}")
115        if isinstance(min_knots, bool) or not isinstance(min_knots, int) or min_knots < _MIN_KNOTS_FLOOR:
116            raise ValueError(f"min_knots must be an integer >= {_MIN_KNOTS_FLOOR}, got {min_knots!r}")
117        if isinstance(pad_hours, bool) or not isinstance(pad_hours, (int, float)) or not 0 < pad_hours <= 24:
118            raise ValueError(f"pad_hours must be a number in (0, 24], got {pad_hours!r}")
119        self.pad_hours = float(pad_hours)
120        self.method = method
121        self.slot_minutes = slot_minutes
122        self.day_grouping = day_grouping
123        self.min_knots = min_knots
124        self._curves: dict = {}
125        self._n_knots: dict = {}
126        self._global_mean: float | None = None
127
128    def _slot_table(self, rooms, timestamps, values) -> pd.DataFrame:
129        ts = pd.Series(pd.to_datetime(timestamps)).reset_index(drop=True)
130        minutes = (ts.dt.hour * 60 + ts.dt.minute).to_numpy()
131        return pd.DataFrame({
132            "room": np.asarray(rooms),
133            "day": _day_key(ts, self.day_grouping),
134            "slot": minutes // self.slot_minutes,
135            "y": np.asarray(values, dtype=float),
136        })
137
138    def _fit_group(self, key, frame: pd.DataFrame) -> None:
139        stats = frame.groupby("slot")["y"].agg(["mean", "count"]).sort_index()
140        if len(stats) < self.min_knots:
141            return
142        centres = (stats.index.to_numpy() + 0.5) * self.slot_minutes / 60.0
143        pad_knots = int(np.ceil(self.pad_hours * 60.0 / self.slot_minutes))
144        self._curves[key] = _fit_curve(self.method, centres, stats["mean"].to_numpy(),
145                                       stats["count"].to_numpy(), pad_knots)
146        self._n_knots[key] = len(stats)
147
148    def fit(self, train: pd.DataFrame) -> "SplineProfile":
149        """Fit the profiles from training data only.
150
151        Args:
152            train: Rows with ``floorspaceid``, ``target_timestamp`` and ``target`` (people).
153
154        Returns:
155            ``self``.
156
157        Raises:
158            ValueError: If ``train`` is empty or required columns are missing.
159        """
160        needed = {"floorspaceid", "target_timestamp", "target"}
161        if needed - set(train.columns):
162            raise ValueError(f"train is missing required columns: {sorted(needed - set(train.columns))}")
163        if train.empty:
164            raise ValueError("cannot fit on an empty training set")
165
166        table = self._slot_table(train["floorspaceid"], train["target_timestamp"], train["target"])
167        self._global_mean = float(table["y"].mean())
168        self._curves, self._n_knots = {}, {}
169        for (room, day), g in table.groupby(["room", "day"]):
170            self._fit_group((room, day), g)
171        for room, g in table.groupby("room"):  # room-level fallback across all days
172            self._fit_group((room, None), g)
173        return self
174
175    def evaluate(self, rooms, timestamps, clip: bool = True) -> np.ndarray:
176        """Evaluate the fitted profile at given rooms and times of day.
177
178        Args:
179            rooms: Room identifier per query.
180            timestamps: Query times (only the time of day and day type are used).
181            clip: Clip negative values to zero (headcount cannot be negative).
182
183        Returns:
184            Expected headcount (people) per query. Groups without a curve fall back to the
185            room-level curve, then to the overall training mean.
186
187        Raises:
188            RuntimeError: If called before :meth:`fit`, or a query falls outside the
189                curve's domain (extrapolation is disabled).
190        """
191        if self._global_mean is None:
192            raise RuntimeError("SplineProfile must be fitted before evaluate")
193        ts = pd.Series(pd.to_datetime(timestamps)).reset_index(drop=True)
194        rooms = np.asarray(rooms)
195        hours = _fractional_hours(ts)
196        days = _day_key(ts, self.day_grouping)
197        out = np.full(len(ts), self._global_mean, dtype=float)
198
199        keys = pd.DataFrame({"room": rooms, "day": days})
200        for (room, day), idx in keys.groupby(["room", "day"]).groups.items():
201            curve = self._curves.get((room, day), self._curves.get((room, None)))
202            if curve is None:
203                continue
204            idx = np.asarray(idx)
205            vals = curve(hours[idx], extrapolate=False)
206            if np.isnan(vals).any():
207                raise RuntimeError("spline queried outside its domain; extrapolation is disabled")
208            out[idx] = vals
209        return np.clip(out, 0.0, None) if clip else out
210
211    def predict(self, df: pd.DataFrame) -> np.ndarray:
212        """Predict the headcount at each row's target time from the fitted profile.
213
214        Args:
215            df: Rows with ``floorspaceid`` and ``target_timestamp``.
216
217        Returns:
218            Predicted headcount (people), never negative.
219
220        Raises:
221            RuntimeError: If called before :meth:`fit`.
222        """
223        return self.evaluate(df["floorspaceid"], df["target_timestamp"])
224
225    def diagnostics(self) -> pd.DataFrame:
226        """Summarise each fitted curve, including whether it would go negative.
227
228        Returns:
229            DataFrame with one row per fitted curve: ``room``, ``day`` (``None`` = all days),
230            ``n_knots``, ``curve_min`` and ``curve_max`` (people, before clipping) over a
231            dense grid of the day.
232
233        Raises:
234            RuntimeError: If called before :meth:`fit`.
235        """
236        if self._global_mean is None:
237            raise RuntimeError("SplineProfile must be fitted before diagnostics")
238        grid = np.linspace(0.0, 24.0, 2401, endpoint=False)
239        rows = []
240        for key, curve in self._curves.items():
241            vals = curve(grid, extrapolate=False)
242            rows.append({"room": key[0], "day": key[1], "n_knots": self._n_knots[key],
243                         "curve_min": float(np.min(vals)), "curve_max": float(np.max(vals))})
244        return pd.DataFrame(rows, columns=["room", "day", "n_knots", "curve_min", "curve_max"])

247class SplineAnomalyForecaster:
248    """Profile at the target time plus a fraction of today's deviation from the profile.
249
250    ``prediction = profile(t + h) + phi * (current - profile(t))`` where ``phi`` is fitted by
251    least squares through the origin on training data. ``phi`` near 1 means "today's
252    deviation persists"; near 0 means "it fades back to the normal profile".
253
254    Args:
255        **profile_kwargs: Passed to :class:`SplineProfile`.
256    """
257
258    def __init__(self, **profile_kwargs):
259        self.profile = SplineProfile(**profile_kwargs)
260        self.phi_: float | None = None
261
262    @staticmethod
263    def _check(df: pd.DataFrame, extra: set) -> None:
264        needed = {"floorspaceid", "timestamp", "target_timestamp", "lag_0m"} | extra
265        if needed - set(df.columns):
266            raise ValueError(f"df is missing required columns: {sorted(needed - set(df.columns))}")
267
268    def fit(self, train: pd.DataFrame, profile: SplineProfile | None = None) -> "SplineAnomalyForecaster":
269        """Fit the profile and ``phi`` from training data only.
270
271        Args:
272            train: Rows with ``floorspaceid``, ``timestamp``, ``target_timestamp``,
273                ``lag_0m`` (current headcount) and ``target``.
274            profile: An already fitted :class:`SplineProfile` (fitted on the same ``train``)
275                to reuse instead of fitting an identical one again. The profile fit is the
276                expensive part, so sharing it halves the cost of fitting both models.
277
278        Returns:
279            ``self``.
280
281        Raises:
282            ValueError: If ``train`` is empty or columns are missing.
283            RuntimeError: If ``profile`` is given but has not been fitted.
284        """
285        self._check(train, {"target"})
286        if train.empty:
287            raise ValueError("cannot fit on an empty training set")
288        if profile is not None:
289            if profile._global_mean is None:
290                raise RuntimeError("the supplied profile must be fitted")
291            self.profile = profile
292        else:
293            self.profile.fit(train)
294        now = self.profile.evaluate(train["floorspaceid"], train["timestamp"])
295        later = self.profile.evaluate(train["floorspaceid"], train["target_timestamp"])
296        a = train["lag_0m"].to_numpy(dtype=float) - now
297        b = train["target"].to_numpy(dtype=float) - later
298        denom = float(np.sum(a * a))
299        self.phi_ = float(np.sum(a * b) / denom) if denom > 0 else 0.0
300        return self
301
302    def predict(self, df: pd.DataFrame) -> np.ndarray:
303        """Predict the headcount at each row's target time.
304
305        Args:
306            df: Rows with ``floorspaceid``, ``timestamp``, ``target_timestamp`` and ``lag_0m``.
307
308        Returns:
309            Predicted headcount (people), never negative.
310
311        Raises:
312            RuntimeError: If called before :meth:`fit`.
313            ValueError: If columns are missing.
314        """
315        if self.phi_ is None:
316            raise RuntimeError("SplineAnomalyForecaster must be fitted before predict")
317        self._check(df, set())
318        now = self.profile.evaluate(df["floorspaceid"], df["timestamp"])
319        later = self.profile.evaluate(df["floorspaceid"], df["target_timestamp"])
320        pred = later + self.phi_ * (df["lag_0m"].to_numpy(dtype=float) - now)
321        return np.clip(pred, 0.0, None)

192        if self._global_mean is None:
193            raise RuntimeError("SplineProfile must be fitted before evaluate")
194        ts = pd.Series(pd.to_datetime(timestamps)).reset_index(drop=True)
195        rooms = np.asarray(rooms)

197        days = _day_key(ts, self.day_grouping)
