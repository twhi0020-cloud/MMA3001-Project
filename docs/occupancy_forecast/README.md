# API documentation

HTML documentation of the `occupancy_forecast` package, generated by [pdoc](https://pdoc.dev) from the
docstrings (Google style). Start at [`../index.html`](../index.html), which leads to the package overview
and one page per module.

GitHub shows `.html` files as source code. To read them as web pages either

- clone the repository and open `docs/index.html` in a browser, or
- turn on GitHub Pages: **Settings -> Pages -> Deploy from a branch -> `main` -> `/docs` -> Save**.

Regenerate after changing any code (a test fails if the docs fall out of step with the code):

```
python scripts/build_docs_and_reports.py --skip-tests
```
