# Data

Raw data is **not** stored in this repository (size: ~1.6 GB; Monash building data).

Place the following files, unzipped, in `data/raw/`:

| File | Description |
|---|---|
| `5occupancySensor_MayToDec2024_9MRows.csv` | Occupancy hub readings (~9.1M rows, 5 floor spaces) |
| `5EnvSensor_MayToDec2024_180kRows.csv` | Environmental sensor readings (~179k rows, 5 sensors) |
| `Sensor_ID_and_Locations.xlsx` | Sensor-to-room lookup (OCC sheet flagged "Incorrect Data" by its authors) |

Source: MMA3001 project dataset 2 (Monash Smart Infrastructure), supplied by the teaching team.
Do not redistribute.
